# CSE110 — Interactive Java Learning Lab

A free, browser-based Java learning platform designed to help beginners develop a clear understanding of programming and prepare for CSE110 midterm and final examinations.

I've been teaching CSE110 for the past 1.5 years, during which I've observed the difficulties students commonly face, particularly with code tracing, problem-solving, and understanding how programs execute.

Drawing on this experience, my teaching materials, and the resources I've gathered over time, I developed this website to make programming more accessible to beginners. Rather than simply providing notes and solutions, the platform focuses on helping students understand what happens behind each line of code through interactive explanations, visualizations, and guided practice.

## Features

* **15 Interactive Lessons:** Covers the syllabus from flowcharts to recursion, with simplified explanations, animations, and interactive examples.
* **Java Execution Visualizer:** Executes code step by step, displaying variable changes, program output, loop iterations, trace tables, arrays, and recursive calls.
* **149 Practice Problems:** Includes exam-style programming, code tracing, output prediction, and problem-solving questions with automated checking, hints, and explanations.
* **Midterm and Final Mock Exams:** Structured practice papers with optional timers, randomized questions, and partial marking.
* **Java Lab:** Allows students to write, execute, and trace Java programs directly in the browser using the supported Java features.
* **Progress Tracking:** Records completed lessons, practice performance, and areas requiring improvement. Progress is stored locally in the browser.

The website is completely free, requires no registration or installation, and works on desktop and mobile devices.
